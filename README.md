# Çalışan Maaş Analizi

Bu proje, Python kullanılarak çalışan maaşları ve departman bilgileri
üzerinden temel veri analizi yapmak amacıyla hazırlanmıştır.

## Projede Yapılan Analizler

- Toplam çalışan sayısı
- Toplam maaş
- Ortalama maaş
- En yüksek maaş
- Departmanlara göre çalışan sayısı
- Departmanlara göre ortalama maaş
- Departmanlara göre en yüksek maaş
- Belirli bir maaşın üzerindeki çalışanların analizi
- Çalışanların maaş durumlarının değerlendirilmesi

## Kullanılan Teknolojiler

- Python
- Matplotlib

## Görselleştirmeler

Projede iki farklı grafik oluşturulmuştur:

- Departmanlara göre ortalama maaş
- Departmanlara göre çalışan sayısı
